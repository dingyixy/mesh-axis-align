# Mesh Axis Align · 网格边定轴

[English](README.md) | [简体中文](README.zh-CN.md)

**用于 Blender 的批量局部轴整理与重合网格去重工具。**

Mesh Axis Align 面向游戏模型导入后的整理流程，也适合 Ninja Ripper 抓取模型并导入 Blender 后使用。插件根据网格整体形状重新确定局部坐标轴，并可删除所选对象中符合匹配条件的重合网格。定轴时保留模型在世界空间中的外形和位置，方便后续沿合理的局部方向缩放、旋转和编辑。

本插件处理已经导入 Blender 的网格，不负责游戏抓取、Ninja Ripper 文件导入，也不恢复原始制作轴向、骨骼、UV 或材质。本项目为独立工具，并非 Ninja Ripper 官方产品。

## 功能

- **仅修改轴向**：批量重设局部轴，不删除任何对象。
- **仅去重**：删除匹配的所选重合对象，不改变保留对象的轴向或网格数据。
- **修改轴向 + 去重**：一次执行两项；保留项定轴成功后才删除其重复项。
- **薄板模式**：按投影凸包外轮廓的最长边确定 X，平面内垂直方向为 Y，法向为 Z。
- **立体模式**：按整体凸包的近似最小体积定向包围盒确定方向，X 最长、Y 次长、Z 最短。
- **自动模式**：根据厚度阈值选择薄板或立体算法。
- 定轴保留世界空间外形、原点位置、拓扑、UV 和材质分配；通过独立网格副本保护共享数据的未选对象。
- 去重优先保留活动对象，否则按对象名排序确定保留项。
- 支持严格材质/UV 匹配、重合容差、逐对象结果报告及 Ctrl+Z 撤销。
- 定轴后默认隐藏物体 XYZ 字母标注，保留正常变换手柄。

## 安装

1. 在本仓库 **Releases → Assets** 下载 **`mesh_axis_align_v1.3.0.zip`**。
2. 打开 Blender **编辑 → 偏好设置 → 插件**。
3. 在菜单中选择 **从磁盘安装 / Install from Disk**，直接选择 ZIP，无需解压。
4. 启用 **网格边定轴 / Mesh Axis Align**。
5. 在三维视图按 **N**，打开 **网格工具 → 网格边定轴**。

请下载上述专用安装包，不要用 GitHub 自动生成的 **Source code (zip)** 代替。升级后若仍显示旧面板，请重启 Blender。

## 使用流程

先通过原有导入工具将模型导入 Blender。切换到**物体模式**，选中待处理网格，然后选择：

| 按钮 | 作用 |
| --- | --- |
| 仅修改轴向 | 保留全部对象，只整理局部轴 |
| 仅去重 | 保留当前轴向，只清理重合对象 |
| 修改轴向 + 去重（全部执行） | 同时完成两项 |

一般从「自动」模式开始。定轴成功后，变换方向切换为「局部」，可以沿新的局部轴缩放或旋转。按 **F9** 可调整上一次操作参数，按 **Ctrl+Z** 撤销；组合操作可以一次撤销。

去重前，将希望保留外观的重合对象设为活动对象。对于可能包含多层表面的导入模型，可先启用「要求材质和 UV 也一致」。

## 去重规则

去重仅在所选对象之间进行，比较量化后的世界坐标、边面结构、面绕序、平滑标记、支持的修改器设置和可见性；仅包围盒大小和位置相同并不足以判为重复。

- 默认重合容差为 **0.00001 Blender 单位**。量化边界可能造成漏判，并非逐点最近距离匹配。
- 「要求材质和 UV 也一致」**默认关闭**，因此几何一致而材质或 UV 不同的对象也可能被删除。
- 严格模式比较已分配的材质数据块身份、UV 数值及额外网格属性；不会判断两个独立材质是否具有相同渲染外观。
- 不焊接顶点，不把不同物体合并为一个网格，也不合并三角化方式不同但视觉相似的表面。
- 删除对象后，不自动清理孤立网格数据。

## 限制与跳过条件

存在父子关系、约束、动画或驱动、形态键、自定义分离法向、链接/库覆盖数据、非正或接近零的变换行列式、几何不足、不支持的修改器等情况时，对象会被跳过。当前「仅去重」也沿用这些对象检查条件。

仅支持通过节点类型检查的部分自动平滑几何节点图；修改器名称为 Auto Smooth 不代表一定支持。定轴会校验世界空间顶点位置；存在支持的修改器时，还会检查求值后的几何与角点法向。校验失败会回退该对象；支持的修改器法向最大允许偏差为 0.1°。

其他注意事项：

- 带骨骼绑定的人物网格通常会被跳过，不提供保留绑定的轴向重建。
- 立体算法为有限候选的近似搜索，不保证全局最小包围盒；对称物体没有唯一最长方向。
- 轴向由形状推断，不等于游戏原始制作轴向；保留原点位置，并将对象缩放归一化，不恢复原始变换。
- 依赖局部/Object/Generated 坐标的程序材质可能改变外观，即使 UV 和材质节点保持不变。
- 高密度网格可能耗时较长；插件不自动保存或备份 `.blend` 文件。

## Python 命令

启用插件后，按需执行其中一条：

```python
import bpy

# 仅定轴
bpy.ops.object.mesh_axis_align(mode='AUTO')

# 仅去重，要求材质和 UV 一致
bpy.ops.object.mesh_axis_deduplicate(match_appearance=True)

# 同时执行两项
bpy.ops.object.mesh_axis_align_and_deduplicate(
    mode='AUTO', match_appearance=True, duplicate_tolerance=0.00001)
```

1.3.0 中 `mesh_axis_align()` 仅执行定轴；旧参数 `remove_duplicates` 已移除。

## 测试与反馈

`tests/` 中包含几何、平滑、去重、撤销及三个操作入口的测试。每份测试应在独立的后台 Blender 工厂场景运行，不要在工作场景中执行：

```text
blender --background --factory-startup --python-exit-code 1 --python tests/test_mesh_axis_align.py
blender --background --factory-startup --python-exit-code 1 --python tests/test_mesh_axis_align_v12.py
blender --background --factory-startup --python-exit-code 1 --python tests/test_mesh_axis_align_v13.py
```

提交 Issue 时，请附 Blender/插件版本、操作与参数、完整跳过或报错信息，以及可复现问题的最小网格。多数几何问题可以用自建简化模型复现，无需提交抓取的游戏资产。
